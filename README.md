## 🚀 Compilation & Execution

All source code adheres to modern C++ standards and compiles with zero warnings under `-Wall -Wextra`:

```bash
# Compile with C++17
g++ -std=c++17 -Wall -Wextra -O2 02-data-structures/linked_list.cpp -o run_list
./run_list

# Compile Graph Algorithms
g++ -std=c++17 -O2 02-data-structures/graph_algorithms.cpp -o run_graph
./run_graph
```
